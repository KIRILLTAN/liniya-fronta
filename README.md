# Линия фронта

Стратегия о современной войне на настоящей карте мира. Выберите страну, стройте заводы, выпускайте БПЛА и ракеты, расставляйте ПВО, ведите войска, флот и дипломатию. Есть ядерное оружие, конструктор вооружений и игра по локальной сети.

## Как играть

1. Откройте [последний выпуск](https://github.com/KIRILLTAN/liniya-fronta/releases/latest) и скачайте `LiniyaFrontaLauncher.exe`.
2. Положите лаунчер в отдельную папку и запустите его.
3. Нажмите «Установить», затем «Играть».

Лаунчер сам проверяет обновления и скачивает новую версию игры в папку `game` рядом с собой. Сохранения лежат в `game\saves`, обновление их не трогает.

Игру можно скачать и без лаунчера: файл `LiniyaFronta.exe` в том же выпуске.

Нужна Windows 10 или 11 с Microsoft Edge WebView2 (в Windows 11 он уже есть).

## Сборка из исходников

Нужны Python 3.8+, `pywebview`, `pythonnet` и `pyinstaller`.

- `build.bat` собирает игру: `dist\LiniyaFronta.exe` и копию «Линия фронта.exe».
- `build_launcher.bat` собирает лаунчер: `dist\LiniyaFrontaLauncher.exe`.
- `release.bat v1.1.0 "что нового"` собирает оба файла и публикует выпуск на GitHub (нужен `gh`).

Без сборки игру можно запустить так: `python main.py`.

## Устройство

- `app/` — сама игра (HTML, CSS, JavaScript; карта на Canvas). Все лимиты и множители лежат в `app/config.js`.
- `main.py` — окно приложения (pywebview), сохранения, сеть.
- `mp_server.py` — сервер комнат для игры по локальной сети.
- `launcher/launcher.py` — лаунчер.
